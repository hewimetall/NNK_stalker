## Core loop (must match engine)

1. **Фаза I — Выход в Зону:** D20 → число жетонов событий на поле.  
2. **Фаза II — Розыгрыш событий:** по очереди D6 → ход к жетонам → карта события.  
3. **Фаза III — База:** хабар, торговля, ремонт → следующий раунд.  
4. **Бой** — мини-игра при атаке/гоп-стопе/патруле.  
5. **Координаты (ККК + D20 + D6)** — для миссий/квестов, не замена фаз раунда.
